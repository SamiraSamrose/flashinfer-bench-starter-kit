# FlashInfer AI Kernel Generation Contest @ MLSys 2026

Optimized GPU kernels for all three competition tracks targeting **NVIDIA Blackwell B200**.

## Quick Start

```bash
# 1. Install dependencies
conda create -n fi-bench python=3.12
conda activate fi-bench
pip install flashinfer-bench modal

# 2. Clone the dataset
git lfs install
git clone https://huggingface.co/datasets/flashinfer-ai/mlsys26-contest
export FIB_DATASET_PATH=/path/to/mlsys26-contest

# 3. Set your track in config.toml
#    definition = "fused_moe"   (Track A)
#    definition = "dsa_topk_indexer_fp8_h64_d128_topk2048_ps64"   (Track B-1)
#    definition = "dsa_sparse_attention_h16_ckv512_kpe64_topk2048_ps64"  (Track B-2)
#    definition = "gdn_decode_qk16_v32_d128_k_last"   (Track C decode)
#    definition = "gdn_prefill_qk16_v32_d128_k_last"  (Track C prefill)

# 4. Copy the relevant kernel to solution/triton/kernel.py

# 5. Pack and test
python scripts/pack_solution.py
python scripts/run_local.py          # local GPU
modal run scripts/run_modal.py       # B200 via Modal
```

## Tracks & Kernels

### Track A — Fused MoE (`solution/triton/kernel.py`)

**Definition:** `moe_fp8_block_scale_ds_routing_topk8_ng8_kg4_e32_h7168_i2048`

| Param             | Value                          |
|-------------------|--------------------------------|
| num_experts       | 256                            |
| num_local_experts | 32                             |
| hidden_size       | 7168                           |
| intermediate_size | 2048 (SwiGLU: 4096 gate+up)    |
| top_k             | 8 (ng=8 groups, kg=4 selected) |
| dtype             | FP8 e4m3fn + BF16 output       |

**Key optimizations:**
- DeepSeek group-limited routing: select 4 of 8 groups → top-8 within selected
- FP8 GEMM1 with 128×128 block-scale dequant + SwiGLU fused in one Triton kernel
- FP8 GEMM2 (intermediate → hidden) with autotuned tiles
- Token permutation sorted by expert for coalesced L2 access

---

### Track B — Sparse Attention (`solution/triton/kernel_track_b.py`)

**Definitions:**
- `dsa_topk_indexer_fp8_h64_d128_topk2048_ps64` — entry: `kernel_topk_indexer`
- `dsa_sparse_attention_h16_ckv512_kpe64_topk2048_ps64` — entry: `kernel_sparse_attention`

DeepSeek V3.2 MLA: 16 Q-heads, 512 compressed KV heads, kpe_dim=64, page_size=64, top_k=2048.

**Key optimizations:**
- Blocked FP8 dot products for page scoring in the indexer
- `torch.topk` for final top-k selection (CUDA-native)
- Flash attention (online softmax) over sparse page set
- Separate positional (kpe) path per MLA design

---

### Track C — Gated Delta Net (`solution/triton/kernel_track_c.py`)

**Definitions:**
- `gdn_decode_qk16_v32_d128_k_last` — entry: `kernel_decode`
- `gdn_prefill_qk16_v32_d128_k_last` — entry: `kernel_prefill`

Qwen3-Next architecture: qk_dim=16, v_dim=32, state layout `[B, H, v_dim, qk_dim]` (k_last).

**Delta rule:**
```
k_hat = k / ‖k‖
delta = v − S @ k_hat
S_new = S + delta ⊗ (β · k_hat)ᵀ
output = (S_new @ q) * gate
```

**Key optimizations:**
- Decode: state tiles in registers; k-norm + beta-scale + gate fused
- Prefill: chunk-wise sequential scan (chunk_size=64), v-tiled for register efficiency
